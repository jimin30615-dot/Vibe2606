# To-Do List 웹페이지 프로젝트

## 목표
오늘의 할 일을 기록하고, 관리하며, 완료 상태를 확인할 수 있는 간단한 웹페이지를 만든다.

## 기능 요구 사항
- 할 일 추가
- 할 일 목록 보기
- 할 일 완료 체크
- 할 일 삭제
- 오늘 날짜 기준으로 할 일을 관리

## 기술 스택
- HTML: UI 구조
- CSS: 디자인 및 레이아웃
- JavaScript: 동작 및 상태 관리

## 다음 단계
1. 기본 HTML 템플릿 작성
2. CSS 스타일 적용
3. JavaScript로 할 일 추가/삭제/완료 기능 구현
4. 로컬 저장(옵션)
